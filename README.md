# Office Supplies Management System

## 1. Introduction

A web-based office supplies management and sales system built with ReactJS, NodeJS, ExpressJS and MySQL.

The system supports product management, categories, suppliers, promotions, shopping cart, checkout, order management and user authentication.

## 2. Technologies

### Frontend
- ReactJS
- React Router
- Axios
- CSS

### Backend
- NodeJS
- ExpressJS
- JWT
- bcryptjs
- MySQL2

### Database
- MySQL
- MySQL Workbench

## 3. Main Features

### Customer
- Register
- Login
- View products
- View categories
- Add products to cart
- Checkout
- View order history
- View order details

### Administrator
- Dashboard
- Product management
- Category management
- Supplier management
- Promotion management
- Order management
